## ⚡ What I do

### 🛡️ Cybersecurity
- Studying and practicing **red team** techniques: recon, enumeration, exploitation, privilege escalation
- **Blue team** mindset: hardening, monitoring, log analysis, incident response
- Applying security to real infrastructure, because the best lab is the one you actually depend on

### 💻 Development & Automation
- **Python** for scripting, automation, tooling and data analysis
- **C/C++** for low-level and performance-sensitive code
- **Bash** to glue systems together and tame Linux boxes
- **Node.js** for services, APIs and integrations
- If I do it twice by hand, the third time a script does it

### 🖥️ Infrastructure & Self-hosting
- Virtualization with **Proxmox** (VMs and LXC containers)
- Linux server administration
- Self-hosted services such as **Nextcloud**: my data, my hardware, my problem

### 🤖 AI, local & cloud
I work with AI end to end, from models running on my own hardware to cloud APIs at scale.
- **Local**: running, tuning and serving open-weight **LLMs** on self-hosted infrastructure, with full control over data and costs
- **Cloud**: building on top of **AI provider APIs** and integrating them with any service that exposes an API
- **Agents & pipelines**: LLM-powered agents, tool calling, RAG and **speech-to-speech voice agents**
- **Integration**: wiring AI into real workflows, so models are actually doing work instead of just chatting
- Picking the right tool for the job: local when privacy and control matter, cloud when power and scale do
